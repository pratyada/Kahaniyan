# Daily SEO Routine — My Sleepy Tale

## Daily (15-20 min)

### Morning Check (5 min)
- [ ] Open Google Search Console > Performance
  - Check impressions, clicks, CTR, average position
  - Note any drops or spikes
- [ ] Check if new pages are indexed (URL Inspection tool)
- [ ] Glance at Google Analytics organic traffic

### Content Block (30-60 min, 3x/week)
- [ ] Write or publish 1 blog post (1,200-2,000 words)
- [ ] Target 1 primary keyword from `KEYWORDS.md`
- [ ] Include internal links to 2-3 other pages
- [ ] Add proper meta title (under 60 chars) and description (under 155 chars)
- [ ] Add 2-3 images with descriptive alt text
- [ ] Include FAQ section with Schema markup
- [ ] Share on social (Twitter, LinkedIn, relevant Facebook groups)

### Technical Check (5 min)
- [ ] Verify new pages are rendering properly (View Source or Google's URL Inspection)
- [ ] Check for any 404 errors in GSC
- [ ] Confirm sitemap is up to date with new content

### Outreach (10 min)
- [ ] Answer 1 Quora question about bedtime stories (link back naturally)
- [ ] Comment on 1 parenting blog post (build relationships)
- [ ] Share story/insight in 1 relevant Reddit/Facebook community

---

## Weekly Review (Friday, 30 min)

### Rankings Check
- [ ] Check target keyword positions (use free tool: Google Search Console or Ubersuggest)
- [ ] Note which pages are gaining/losing
- [ ] Identify new keyword opportunities from GSC "Queries" tab

### Content Audit
- [ ] Review this week's published posts — are they indexed?
- [ ] Check which posts got the most impressions
- [ ] Plan next week's 3 posts based on what's working

### Technical Health
- [ ] Check Core Web Vitals in GSC (any regressions?)
- [ ] Review crawl stats — is Googlebot visiting regularly?
- [ ] Fix any new 404s or crawl errors

### Link Building
- [ ] Send 3-5 outreach emails to parenting bloggers
- [ ] Look for broken links on competitor pages (offer your content as replacement)
- [ ] Submit to 1-2 relevant directories (app directories, parenting resources)

### Social & Distribution
- [ ] Share best-performing post again on different platform
- [ ] Engage with parents in 2-3 online communities
- [ ] Post a story snippet or parenting tip on social media

---

## Monthly Deep Dive (1st of month, 1 hour)

### Performance Review
- [ ] Compare organic traffic month-over-month
- [ ] Review top 20 keywords by impressions — which are close to page 1?
- [ ] Identify "striking distance" keywords (positions 8-20) — optimize those pages
- [ ] Check competitors — any new content from them?

### Content Strategy
- [ ] Plan next month's content calendar (12-15 posts)
- [ ] Identify content gaps — keywords you're not covering yet
- [ ] Update/refresh any posts older than 3 months
- [ ] Create 1 new landing page for an underserved keyword cluster

### Technical SEO
- [ ] Run a full site crawl (Screaming Frog free or Sitebulb)
- [ ] Check all pages are in sitemap and indexed
- [ ] Review page speed (PageSpeed Insights) — fix any regressions
- [ ] Ensure Schema markup is valid (Google Rich Results Test)

### Link Profile
- [ ] Check new backlinks acquired (GSC > Links)
- [ ] Review referring domains — any toxic links?
- [ ] Set 5 link building targets for next month
- [ ] Pitch 1 guest post to a high-DA parenting site

### Conversion Optimization
- [ ] Check which pages drive the most app installs/signups
- [ ] A/B test CTAs on top-performing pages
- [ ] Add internal links from high-traffic pages to conversion pages

## Time Budget (Weekly)

| Activity | Time/Week |
|----------|-----------|
| Morning checks (daily) | 35 min |
| Content writing (3x) | 2-3 hours |
| Outreach (daily) | 50 min |
| Weekly review | 30 min |
| **Total** | **~5 hours/week** |

This is the minimum viable SEO effort for a solo founder. Scale up content production as you see results (usually month 2-3).
